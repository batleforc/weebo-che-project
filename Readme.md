# Weebo Che Project

This project is a wrapper around the diffent project of the che ecosys that i will need to mutate.

I find the provided image lacking in many aspect, it's for that reason that i made my own [WeeboDevImage](https://github.com/batleforc/WeeboDevImage), especially the [Che-Min-Mise](https://github.com/batleforc/WeeboDevImage/tree/main/che-min-mise) who is my latest base image using [Mise](https://mise.jdx.dev/) and [ChezMoi](http://github.com/twpayne/chezmoi).

An example of this setup in action can be [found here](https://github.com/batleforc/weebo-dotfiles-che).
